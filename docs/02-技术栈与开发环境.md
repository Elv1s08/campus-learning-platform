## 2 版本基线说明

### 2.1 已确定的版本

项目立项阶段提出的技术栈建议为 Spring Boot 3.x。实际创建工程时采用 **Spring Boot 4.1.1**，该选择与当前生态一致，无需回退，理由如下：

1. **Spring AI 2.0.0 GA 明确以 Spring Boot 4.0 / 4.1 与 Spring Framework 7.0 为基线**。项目后续必须接入 Spring AI，使用 Boot 4.1.1 可直接兼容，无需二次迁移。
2. **Spring Boot 3.5 已于 2026 年 6 月 30 日终止维护**，不再提供安全补丁，新项目不应采用。
3. Spring Boot 4 的部分构件名称发生变化，例如 Web 模块由 `spring-boot-starter-web` 更名为 `spring-boot-starter-webmvc`。项目 pom.xml 已按新命名引入，可正常编译。

**结论：保持 Spring Boot 4.1.1，不再降级到 3.x。开发周期内锁定版本，中途不升级。**

### 2.2 版本兼容性注意事项

| 事项 | 说明 |
|---|---|
| MyBatis-Plus | Boot 4 需使用 `mybatis-plus-spring-boot4-starter`，非传统 `mybatis-plus-spring-boot3-starter` |
| MyBatis-Plus 包路径 | Service 实现类位于 `com.baomidou.mybatisplus.spring.service.impl`，与 3.x 时代的 `extension.service.impl` 不同 |
| Spring AI | 接入时必须选择 2.0.x 系列，1.x 系列不兼容 Boot 4 |
| Lombok | 需在编译器插件中配置 annotationProcessorPaths，否则注解不生效 |

MySQL 8 默认认证方式可能导致连接失败，需在驱动属性中设置：

### 4.4 已建数据表

**sys_user（用户表）**

```sql
CREATE TABLE sys_user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    real_name VARCHAR(50),
    role VARCHAR(20) NOT NULL,
    status TINYINT NOT NULL DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
        ON UPDATE CURRENT_TIMESTAMP
);
```

字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键，自增 |
| username | VARCHAR(50) | 登录账号，唯一 |
| password | VARCHAR(255) | BCrypt 加密后的密码 |
| real_name | VARCHAR(50) | 真实姓名 |
| role | VARCHAR(20) | 角色标识，取值 STUDENT / TEACHER / ADMIN |
| status | TINYINT | 状态，1 启用，0 停用 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间，自动维护 |

## 5 后端工程结构

### 5.1 当前目录结构

```text
campus-learning-platform/
├── campus-server/
│   └── src/main/java/com/campus/campus_server/
│       ├── CampusServerApplication.java      启动类
│       ├── common/ApiResponse.java           统一响应封装
│       ├── config/PasswordConfig.java        BCrypt 加密 Bean
│       ├── controller/HealthController.java  健康检查
│       ├── controller/SysUserController.java 用户接口
│       ├── dto/LoginRequest.java             登录入参
│       ├── entity/SysUser.java               用户实体
│       ├── mapper/SysUserMapper.java         数据访问接口

│           ├── SysUserService.java
```

### 5.2 目标模块结构

随功能推进，后端按业务域分包，保持单体架构，不拆微服务：

```text
campus-server/
├── common/       统一返回、异常处理、工具类
├── auth/         登录、JWT、权限
├── user/         用户与角色
├── subject/      学科管理
├── knowledge/    文档、知识块、向量化
├── chat/         会话、消息、RAG 问答
├── question/     题库与错题本
├── study/        学习记录与统计
├── notice/       公告与消息
└── admin/        后台统计
```

整体仓库规划：

```text
campus-learning-platform/
├── campus-server/     Spring Boot 后端
├── campus-web/        Vue 前端
├── deploy/            Docker Compose 编排文件
└── docs/             需求、数据库、接口、架构文档
```

### 5.3 分层职责

| 层 | 职责 |
|---|---|
| Controller | 接收 HTTP 请求、参数校验、返回统一响应，不承载业务逻辑 |
| Service | 业务规则处理、事务边界 |
| Mapper | 数据访问，继承 MyBatis-Plus `BaseMapper` |
| Entity | 与数据库表映射的实体对象 |
